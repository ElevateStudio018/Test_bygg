# Test Bygg

AI-återskapad startsida för ett bygg- och anläggningsföretag, med påhittat företagsnamn ("Test"). Ren HTML, CSS och JavaScript utan beroenden.

- `index.html` – startsidan
- `css/style.css` – layout, färger och responsiv design
- `js/main.js` – megameny (desktop) och mobilmeny
- `assets/` – bilder och ikoner

## Kör lokalt

```sh
python3 -m http.server 8000
# öppna http://localhost:8000
```
